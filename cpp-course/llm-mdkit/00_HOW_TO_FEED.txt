Paste order for a fresh chat:

  1. 04_tutor_rules.txt          always, first
  2. 03_architecture_and_stack.txt
  3. 05_binary_contracts.txt     whenever parsing is in scope
  4. 01_step_by_step.txt         only the current milestone section
  5. 02_concepts_learned.txt     the rows for that milestone
  6. 06_review_checklist.txt     when asking for a review

Then add your own message, for example:

  "I am on M1. I have not written code yet. Teach the next slice only.
   My compiler is Apple Clang. Do not write the whole decoder."

Do not paste the entire cpp-course. Point the model at a lesson file
only when a concept in 02 says to.

The human course is cpp-course/00 through 17. These llm-mdkit files are
the operating brief. Build mdkit in a NEW git repo, not inside
TradingEngine.
