M0
  Translation unit, -Wall, sanitizers, CMake target

    lesson 01, 14

  Fixed-width ints, unsigned wrap, enum class
    Price4, shares, Side
    Python ints do not wrap; "BUY" strings are not a type
    lesson 02
  Byte order and alignment
    load_be / load_be48
    struct.unpack('>I') exists; doing it wrong in C++ is UB, not an exception
    lesson 04, 08
  span, string_view, lifetime
    Symbol view into the message
    A Python str owns its data; a view does not
    lesson 04, 12
  Templates and concepts
    Handler concept, decode_message<H>
    Python duck typing is runtime
    lesson 09
  Error policy without exceptions
    on_error, truncated tail
    Python would raise
    lesson 10
  switch on a type tag, exhaustive lengths
    ITCH type byte
    no match/case on raw bytes
    lesson 02, 12

M2

    price levels vs order index vs locate table

    lesson 06
  Iterator and reference invalidation

    dict mutation during lookup is messy; this is UB
    lesson 07, 08
  Aggregates and invariants
    level shares and order count stay in sync
    no compiler-enforced invariant in a dict
    lesson 03
  std::optional instead of -1

    None

  Header vs source, ODR, tests as spec
    book.hpp / book.cpp / the scenario test

CONCEPTS TO NOT SPEND TIME ON FOR THIS PROJECT
  Go goroutines, chi, Next.js, httplib as the architecture,
  shared_ptr ownership graphs, matching-engine FillAndKill.
  Those are lessons 13 and 15. Skim them so you can say why mdkit
  is different.
